![Build](https://img.shields.io/badge/build-passing-brightgreen) ![.NET 8](https://img.shields.io/badge/.NET-8.0-512BD4) ![Platform](https://img.shields.io/badge/platform-Windows-0078D6) ![License](https://img.shields.io/badge/license-MIT-blue) ![Release](https://img.shields.io/github/v/release/aut0mat1clol/AvtomatChat)

Десктоп-приложение на **C# / WPF (.NET 8)** для стримеров: чат Twitch в реальном времени, озвучка сообщений (TTS, офлайн, без API-ключей), алерты и настраиваемый OBS-оверлей со звуком — всё в одном exe с автообновлением.

## Возможности

### Чат
- 📺 Подключение к чату любого Twitch-канала **без авторизации** (анонимный IRC, OAuth-токен не нужен)
- 🔌 **Автопереподключение**: обрывы соединения чинятся сами за 2–15 секунд — долгие стримы без ручных переподключений
- 😀 **Эмоуты Twitch** (глобальные + сабские) и **7TV** (глобальные + канальные), анимированные — анимируются
- 💜 Подсветка сообщений **«Выделить моё сообщение»** за баллы канала
- 📢 **Объявления** (/announce) с текстом, 🎉 алерты сабов/ресабов/подарков/рейдов
- 🎭 Корректный **/me** — курсивом в цвете ника
- 🔗 **Ссылки** сокращаются до домена и кликабельны; по галочке ссылки на картинки показываются **миниатюрой**
- 🗑 Удалённые модераторами сообщения: у стримера — зачёркнутый текст с пометкой «Deleted», из OBS исчезают полностью
- 👋 События «зашёл/вышел» (опционально, отдельно для окна и OBS)
- 🔍 Масштаб чата: Ctrl + колесо (50–300%), Ctrl+0 — сброс
- 🖼 Кнопка **«Только чат»** в шапке окна — компакт-режим без интерфейса

### Озвучка (TTS)
- 🔊 Очередь озвучки — сообщения читаются по одному; кнопки «Пропустить» и «Очистить очередь»
- 🗣 Выбор голоса с пометкой языков (`[RU]`, `[EN]`, `[RU/EN]`), скорость, громкость
- 🔑 **Режим триггера**: озвучивать только сообщения с ключевым словом (например `!tts`)
- 🤖 **Список исключений**: боты (Nightbot, StreamElements и др. — уже вписаны) не озвучиваются
- 🧹 Фильтры: пропуск `!команд`, замена ссылок словом «ссылка», не читать эмоуты, анти-спам, обрезка длинных сообщений
- 🔈 Вывод звука: на ПК, в OBS (в микс стрима через браузерный источник) или туда и туда

### OBS-оверлей
- 🎥 Встроенный сервер `http://localhost:8085/` — добавь как источник «Браузер» в OBS
- 🎨 **Лайауты**: 4 пресета (Классика, Компактный, Пузыри, Крупный текст) + поле для своего CSS
- 🔤 **Шрифты работают из коробки**: всё, что установлено в Windows (включая «только для меня»), оверлей раздаёт браузеру OBS сам; веб-шрифты — через `@import`
- ⏳ **Исчезание сообщений**: настраиваемый таймер (0–120 с) с плавным затуханием
- ✨ Плавные анимации: сообщения мягко появляются, исчезают и сдвигаются — без дёрганий
- 🔉 Звук TTS может идти прямо из источника — попадает в микс стрима

### Окно приложения
- 💬 Чат в окне рендерится **той же страницей, что и OBS-оверлей** (WebView2) — пресеты, CSS и шрифты выглядят одинаково везде, плюс стримерские фичи: отметки времени, содержимое удалённых сообщений, прокрутка истории
- 🖥 **Трей**: при подключённом чате крестик прячет окно в трей (чат и озвучка работают); из меню трея — вкл/выкл озвучки, пропустить, очистить очередь/чат, выход
- ⚙ Все настройки — в отдельном окне, применяются мгновенно

### Обновления
- 🔄 **Автообновление**: проверка при запуске (без лимитов GitHub API), баннер с кнопками «Подробнее» (список изменений прямо в приложении) и «Обновить и перезапустить»
- 💾 Настройки сохраняются между запусками (`%APPDATA%\AvtomatChat\settings.json`)
- 🛡 Ошибки не роняют приложение: пишутся в `crash.log`

## Установка

**Готовый exe:** скачай `AvtomatChat-win-x64.zip` из [последнего релиза](https://github.com/aut0mat1clol/AvtomatChat/releases/latest), распакуй и запусти `AvtomatChat.exe`.

Требуется **Windows 10/11**, [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) и WebView2 Runtime (есть в Windows 11 и почти на всех Windows 10; если чего-то нет — система предложит установить). Дальше обновления приложение ставит само.

## Запуск из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0):

```bash
git clone https://github.com/aut0mat1clol/AvtomatChat.git
cd AvtomatChat
dotnet run
```

Сборка одним exe:

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

## Как пользоваться

1. Введи имя канала (например `lirik` — без `#` и без ссылки) и нажми **Подключиться**.
2. Сообщения появляются в чате и озвучиваются по очереди.
3. **«⚙ Настройки»** — озвучка, алерты, лайаут оверлея, события чата, обновления. Кнопка **Тест голоса** проверяет звук без подключения.
4. Кнопка в шапке окна — режим **«Только чат»**; крестик при подключённом чате сворачивает в **трей**.

### Подключение к OBS

1. В OBS: **Источники → + → Браузер**, URL `http://localhost:8085/`, размер под макет (например 500×800).
2. Для звука TTS в стриме: включи галочку **«В OBS (через оверлей)»** в настройках.
3. В свойствах источника включи **«Управлять звуком через микшер»**, чтобы регулировать громкость TTS в микшере OBS.
4. После смены лайаута/CSS: свойства источника → «Обновить кэш текущей страницы».

### Кастомизация оверлея

Пресет + свой CSS в настройках. Классы: `.msg` — сообщение, `.msg .nick` — ник, `.msg img.emote` — эмоут, `.msg.alert` — алерт, `.msg.highlighted` — выделено за баллы, `.msg.sysmsg` — зашёл/вышел, `.msg .me` — /me, `.msg img.linkpreview` — превью картинки. Шрифт: `.msg { font-family: 'ИмяШрифта'; }` — подойдёт любой установленный в Windows.

## Больше голосов

System.Speech видит «классические» голоса SAPI5:

1. **RHVoice (рекомендуется, бесплатно)**: качественные русские голоса — Aleksandr, Anna, Elena, Irina и другие. Скачать: **[rhvoice.ru/ru-voices](https://rhvoice.ru/ru-voices/)** (установщик SAPI5 — движок ставится вместе с голосом, после перезапуска программы голоса появятся в списке).
2. **Штатно**: `Параметры → Время и язык → Речь → Добавить голоса`.
3. **Скрытые голоса Windows**: копирование веток реестра из `HKLM\SOFTWARE\Microsoft\Speech_OneCore\Voices\Tokens` в `HKLM\SOFTWARE\Microsoft\Speech\Voices\Tokens` (ищи «unlock Windows TTS voices»).
4. **Сторонние SAPI5-голоса** (Ivona, Acapela и др.) появятся в списке после установки.

## Структура проекта

| Файл | Назначение |
|---|---|
| `TwitchIrcClient.cs` | IRC-клиент Twitch: PRIVMSG, теги (эмоуты, /me, хайлайты), USERNOTICE-алерты, CLEARMSG/CLEARCHAT, автопереподключение |
| `TtsService.cs` | Очередь озвучки, фильтры, триггер, игнор-лист, WAV для OBS |
| `SevenTvService.cs` | Эмоуты 7TV (API v3) + разбор сообщений на текст/эмоуты (Twitch + 7TV) |
| `ObsOverlayServer.cs` | HTTP-сервер: страница оверлея (OBS/стример/предпросмотр), JSON сообщений, аудио TTS, раздача шрифтов, лайауты |
| `UpdateService.cs` | Автообновление через GitHub Releases (без лимитов API), список изменений |
| `AppSettings.cs` | Сохранение настроек в JSON |
| `MainWindow.xaml(.cs)` | Главное окно: чат (WebView2), подключение, трей, компакт-режим, баннер обновления |
| `SettingsWindow.xaml(.cs)` | Окно настроек |
| `App.xaml.cs` | Глобальный перехват ошибок, crash.log |

## Выпуск новой версии (заметка для себя)

1. Поднять `<Version>` в `AvtomatChat.csproj` (должна совпадать с тегом релиза).
2. `dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish`
3. Запаковать exe в `AvtomatChat-win-x64.zip` (имя ассета важно — его ищет автообновление).
4. Создать релиз с тегом версии и прикрепить zip — пользователи обновятся сами. Описание релиза показывается в приложении по кнопке «Подробнее» (символы `@слово` брать в бэктики!).
